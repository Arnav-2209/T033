# Requirements decision register

This register is carried forward from Phase 0. A recommendation is not a ratified business rule. Update `Status`, decision owner and date before implementing a dependent workflow.

| DEC-022 | Submission retry key             | Duplicate submissions must be prevented, but no API retry mechanism is specified.                                                                                            | Submit requires an idempotency key; key is unique in DB, scoped to the owning student, and reused against a different grievance returns 409.                                                                                                                          | Recommended reliability mechanism                      |
